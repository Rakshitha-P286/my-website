# BuildMart 🏗️🪨

A full-stack e-commerce platform developed for ordering construction materials such as M-Sand and P-Sand with features including product ordering, review management, image uploads, and order tracking.


## 📌 Project Overview

BuildMart is designed to simplify the process of purchasing construction materials online. The platform allows users to:
- browse available sand products
- place orders online
- upload product reviews with images
- manage customer orders
- improve accessibility for construction material purchasing

The project focuses on creating a user-friendly and scalable online ordering system for construction materials.


## 🚀 Features

- 🛒 Product Ordering System
- 🪨 M-Sand & P-Sand Product Listings
- 📦 Order Management
- ⭐ Product Reviews & Ratings
- 🖼️ Review Image Upload Feature
- 👤 User Information Collection
- 📱 Responsive User Interface
- 🔍 Product Browsing & Selection

## ⚙️ System Workflow

User Visits Website
        ↓
Browse Construction Materials
        ↓
Select Product & Place Order
        ↓
Order Details Sent to Backend
        ↓
Data Stored in Database
        ↓
User Can Add Reviews & Upload Images
        ↓
Reviews Displayed on Product Page
